# ChessEng — Senior Capstone Archive

This repository is associated with my 2025 engineering senior capstone at **Science Leadership Academy in Philadelphia**.

## Project background

My capstone explored the design of a browser-based chess application and engine. The project write-up describes experimenting with:

- JavaScript and bitboard-based board representations
- Depth-limited minimax search and alpha-beta pruning
- Position-evaluation heuristics
- A React / Chessboard.js interface
- Node.js / Express and WebSocket-based communication

**[Read the original capstone write-up](https://scienceleadership.org/blog/willis_osorio_capstone_2025).**

## What is actually in this repository?

**This is an incomplete code archive, not a working copy of the chess application.** At present, the `code` file is a shell script for detecting processor architecture and selecting a Stockfish build. The repository does **not** currently contain the React frontend, Node.js backend, or chess-engine implementation described in the write-up.

There are therefore no installation or run instructions for the full application here.
